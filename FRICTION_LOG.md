# Friction log: Megastructures TV

Kept while building, October 7 2026, on an Apple Silicon Mac with no Fire TV device, no Java or Android Studio and no AWS SigV4 credentials (only an Amazon Bedrock API key). Severity: High blocks the plan, Medium costs hours or changes the design, Low costs minutes.

## Platform decision (research, 15 minute time box)

Question: how do you ship a WebGL web app to Fire TV in 2026, and how do you run it without hardware on a Mac?

| Option | Evidence found | Verdict |
|---|---|---|
| Fire OS app: Android APK with a full screen WebView | Runs on every Fire TV Stick in use today. Amazon documents web app key codes for Fire TV (D-pad 37 to 40, Select 13, Play/Pause 179, Rewind 227, Fast forward 228, Back 4) on "Supporting Controllers in Web Apps". Amazon's "Use an Android TV Emulator" page says to test Fire OS 8 apps on an Android 11 (API 30) TV emulator image. | **Chosen** as the primary target. |
| Vega OS: React Native for Vega with the Vega WebView component | Vega SDK 0.24 release notes: WebView based on Chromium 144, RN 0.83. "Develop your app with WebView" shows `import { WebView } from '@amazon-devices/webview'` with `allowSystemKeyEvents` and `allowFileAccess`. The Vega Virtual Device runs on macOS (Apple Silicon recommended, about 20 GB, Rosetta 2). | Promising second target. The WebView page does not say whether WebGL or WebGL2 is available, so a Three.js app could not be confirmed. Not built. |

I could not read the hackathon rules page with an automated fetch (HTTP 403), so I went by the plan: the video must show the app on a Fire TV device or a simulator. Nothing I found said Vega is required, so Fire OS stays primary.

## What worked well

- The Fire TV web key codes are short and clear, and the D-pad really does arrive as plain arrow keys, so the whole UI can be built and tested with a laptop keyboard.
- Bedrock Converse with tool use needed no SDK at all: one `fetch`, one JSON body, and tool calls that were valid against the schema every time in testing.
